# СП Кошелёк
С этим приложением вы можете переводить деньги другим игрокам и между своими счетами, а также создавать отдельные наличные счета и всегда видеть свой общий баланс.

### Основные возможности
- Денежные переводы другим игрокам
- Переводы между своими счетами
- Создание счетов для наличных средств
- Подсчёт общего баланса с наличных и банковских счетов
- Поддержка серверов СП и СПм

### Безопасность
Для доступа к большинству функций приложения, необходимо иметь хотя бы одну активную карту.

Данные карт остаются на вашем устройстве, и никуда не отправляются. Вы можете поменять эти данные в любой момент, тогда с карты будет нельзя совершать сторонние операции.
